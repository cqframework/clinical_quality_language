# Engine

This module contains the CQL engine used to evaluate ELM libraries. It is a Kotlin Multiplatform project supporting the JVM and JS targets.

## Contents

- [Evaluation API](evaluation-api.md) - The API for evaluating CQL libraries and expressions.
- [Evaluation Tracing](evaluation-tracing.md) - Using evaluation traces for execution results.
- [CQL Value Types](cql-value-types.md) - Kotlin classes used to represent CQL values during evaluation.
- [CQL Code Coverage](cql-code-coverage.md) - Collecting and reporting CQL code coverage.

For information on migrating from CQL engine v4 to v5, see the [migration guide](../docs/migration-guides/v4-to-v5-migration.md).
